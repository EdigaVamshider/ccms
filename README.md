# CCMS — Web Application

A web-based application with separate interfaces for students and administrators, including landing pages and dashboards.

## Features

- Student interface
- Administrator interface
- Dashboard pages
- HTML, CSS, and JavaScript frontend
- Supabase integration

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Supabase
- Vercel (deployment)

## Project Structure

| File | Purpose |
|---|---|
| `index.html` | Main application page |
| `landing.html` | Landing page |
| `student.html` | Student interface |
| `admin.html` | Administrator interface |
| `dashboard.html` | Dashboard |
| `index.css` | Main stylesheet |
| `index.js` | Main application logic |
| `student.js` | Student functionality |
| `admin.js` | Administrator functionality |
| `dashboard.js` | Dashboard functionality |
| `supabase.js` | Supabase integration |

## Setup

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Configure the required Supabase project settings.
4. Run the application using a local development server.
5. Verify that the required database tables and access policies are configured.

## Security

- Never commit passwords, service-role keys, or other private credentials.
- Configure appropriate Supabase Row Level Security (RLS) policies.
- Keep database access restricted to authorized users.
